# Design decisions

Record a decision here when its reason or tradeoff would be hard to recover from the code and tests: for example, changing the GM/player socket boundary, world-state ownership, a public hook contract, or browser-test isolation. Ordinary fixes do not need a decision record.

Use one short file per decision, named `YYYY-MM-DD-short-topic.md`. Include the context, the choice, why it was made, and any consequence that a future change must account for. Link the affected code and tests. Keep the record about the decision made; use issues or pull requests to track implementation work.
